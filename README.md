# hxwl-11 眼科验光质控工作台

视力、屈光参数与设备校准联动的验光质控与处方流转

## 技术栈

React + Vite + TypeScript + CSS，localStorage 本机持久化（无后端）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 质控流程

1. **设备台账**：登记设备编号与校准有效期；校准过期或今天到期的设备会被标红，可在侧栏续期。
2. **录入**：按患者 + 眼别录入三次球镜、柱镜、轴位及设备编号。
3. **判定**（`src/domain/qc.ts`）：
   - 设备校准过期/到期，或设备不在台账 → 拦截；
   - 三次轴位跨度 > 5°（按 0–180° 圆周计算，跨 0° 不误判）→ 拦截；
   - 任一不通过先存 **待复核**，不能直接出方。
4. **续期重测**：设备续期后对待复核档案追加一组读数，原读数与失败原因永久保留。
5. **复核出方**：最新一次测量质控通过后才能复核，再出方；处方取球镜/柱镜中位数、轴位圆周均值。
6. **锁定与版本**：出方后值锁定不可改，改动需另开新版本（版本链可追溯），原处方继续保留。
7. 数据保存在浏览器本机（`hxwl-11-qc-db-v1`），关闭再打开仍可查询。
