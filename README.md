# hxwl-11 眼科验光质控工作台

验光录入与设备校准状态联动，质控通过后方可出方。

## 技术栈

React + Vite + TypeScript + CSS，本机使用 localStorage 持久化。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 质控流程

1. **档案与设备**：维护患者档案和设备校准台账（设备编号、校准到期日、续期）。
2. **三次读数录入**：按患者 + 眼别（右 OD / 左 OS）录入三次球镜、柱镜、轴位及设备编号，页面实时预览判定结果。
3. **判定规则**：
   - 设备校准日期早于今天（过期）→ 拦截；
   - 三次轴位跨度超过 5°（按 180° 周期计算，跨 0° 不误判）→ 拦截；
   - 命中任一只保存为**待复核**，不能直接出方。
4. **续期与重测**：设备续期后重测，判定追加为新版本；原读数、失败原因、复核结论全部保留可查。
5. **复核出方**：待复核记录当前版本判定通过后，可「复核通过并出方」。
6. **锁定与版本**：出方后值锁定不可改；修改只能通过重测另开版本，历史版本不覆盖。
7. **持久化**：全部数据存 localStorage（`hxwl11-qc-state-v1`），关闭浏览器再打开仍可查询。

## 代码结构

- `src/qc/types.ts`：患者 / 记录 / 版本 / 设备领域模型
- `src/qc/judge.ts`：校准有效期、轴位跨度、出方均值等纯判定逻辑
- `src/qc/store.ts`：localStorage 持久化与录入、重测、复核、续期动作
- `src/App.tsx`：看板、设备台账、档案、录入表单、待复核队列、已出方列表
